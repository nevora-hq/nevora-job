副業をしている人は、世の中にどれくらいいるのでしょうか。自分と同じ働き方の人だと何割なのか、気になりませんか？

調べてみると、全体の割合のほかに、正社員とパート・契約社員などの違い、住んでいる県ごとの割合、「他の仕事もしたい」人の割合まで出てきて、どれを見ればいいのか迷うかもしれません💦

全体・働き方別・県別、それぞれの割合の見方を詳しく説明していきます。

## 副業をしている人の割合は、誰をどう数えた数字なのか

割合は、誰の中の何割かで意味が変わります。この記事で使う数字は、国の調査にもとづく値です。全体の値は、農業・林業などを除いて働く人に占める割合で%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%、正規と非正規の値は、雇用形態別に分けた値です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

つまり、全体の割合と自分の区分の割合は、別の数字として並んでいます。調査での副業は、主な仕事以外に就いている仕事のことです%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

### 契約社員やパート・派遣は、どちらの区分で見るのか

調査の区分は、勤め先でどう呼ばれているかで分けられています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。契約社員で、仕事の中身が正社員と変わらないときも、調査では呼び名で非正規の側に入ります。

呼ばれ方ごとの区分と、調査での呼び名の決まりは、次の表のとおりです%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

| 勤め先での呼ばれ方 | 調査での区分 | 調査での呼び名の決まり |
| --- | --- | --- |
| 正社員・一般職員 | 正規 | 「正社員」「一般職員」などの呼び名 |
| パート・アルバイト | 非正規 | 時間や日数は問わない |
| 派遣社員 | 非正規 | 労働者派遣事業所に雇われ、そこから派遣されて働く人。港湾運送・建設・警備・医療関係の業務などは含めない |
| 契約社員 | 非正規 | 専門的な職種に従事させる目的で契約に基づき雇われ、雇用期間の定めがある人 |
| 嘱託 | 非正規 | 「嘱託職員」やそれに近い名称で呼ばれている人 |
| 上のどれでもない | 非正規のその他 | 上の呼び名に当たらない雇用者 |
| 会社などの役員 | どちらにも入らない | 社長・取締役・監査役、団体の理事・監事など |
| 自営業主 | どちらにも入らない | 個人経営の商店主・開業医・著述家など、自分で事業を営んでいる人 |

会社などの役員と自営業主は、正規にも非正規にも入りません%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。この2つに当たる人は、次の節の正規・非正規の割合には当てはまりません。

> 💡 NEVORAポイント
> 調査上の区分と勤務先の呼び名は、ぴったり重ならない場合があります。迷ったら、==普段の職場での呼ばれ方==に近い方を選んでください。

### 2つの仕事をしているとき、どちらが副業に数えられるのか

何が主な仕事になるかは、次の表の決まりで分けられています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

| 状況 | 主な仕事の決まり方 |
| --- | --- |
| 時間に差がある | 就業時間の長い方 |
| 収入に差がある | 収入の多い方 |
| 決められない | 回答者が主と考える方 |

表の「決められない」は、時間でも収入でも決められない場合のことです。時間の長い方と収入の多い方が食い違うときの優先順は、決まりに書かれていません%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。数え方で迷うときは、勤め先での呼び名より先に、2つの仕事のうち時間が長いのはどちらか、収入が多いのはどちらかを書き出してみてください。

## 正規と非正規で並べた、副業をしている人の割合

副業をしている人の割合は、全体で4.8%、正規で2.5%、非正規で7.2%と、区分でかなり違います%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。3つの値の差は、次のグラフで見比べてみてください。

5年前と比べると、副業をしている人の割合は、全体で0.9ポイント、正規で0.6ポイント、非正規で1.3ポイント上がっています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

落とし穴は、全体の4.8%を、自分の働き方の割合として読むことです。自分が正社員なら2.5%、契約社員やパートなら7.2%と、==自分の区分の割合==で読むと、見え方が変わります。

> 💡 NEVORAポイント
> 全体の割合は、自分の区分の割合の代わりになりません。==自分の働き方の割合==は、自分の区分の行で読んでください。

割合から分かるのは、副業をしている人が全体の中でどれくらいかまでです。勤務先の人の受け止め方までは分かりません。副業を始めるときは、勤務先のルールを先に確かめてみてください。就業規則の読み方は[就業規則に副業禁止とあったら｜会社が止められる場面の見分け方](/posts/fukugyo-shugyokisoku-kakunin)で、副業を認める会社の割合は[副業を認める会社は何割？｜調査の規模別の数字と自社の確かめ方](/posts/fukugyo-kigyo-ninchi-wariai)で整理しています。

副業をしている人の人数がどう動いてきたかは、[副業をしている人の数がいつから増えたかをまとめた記事](/posts/2026-09-11_fukugyo-data-de-miru-genjo)に載せています。

## 住んでいる県の割合は、働き方の数字と並べていいのか

県の割合は、働き方を問わず、その県で副業をしている人をまとめた値です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。全国が4.8%で、都道府県別では京都府が7.5%と最も高く、東京都が6.5%、和歌山県が5.6%と続きます%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。47都道府県で最も低いのは、宮崎県の3.3%です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

### 自分の県の割合を地方から探す

%%総務省統計局「令和4年就業構造基本調査」(2022年10月1日現在)%%

自分の県の数字を見つけたら、その数字は、働き方とは別に読みます。出典の表には正規・非正規の内訳が載っていないので、「東京の正社員の割合」は読み取れません%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

「東京は6.5%だから、正社員の2.5%は低すぎる」と並べて見ると、働き方の違いと地域の違いを混ぜた比べ方になってしまいます💦 ^^県の割合は、働き方の割合とは別の数字として書き留めてください^^。

## 「他の仕事もしたい」人の割合が数えているもの

副業の割合と並んで出てくる数字に、「他の仕事もしたい」人の割合があります。調査では追加就業希望者と呼ばれ、今の仕事を続けながら他の仕事もしたいと思っている人のことです%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。全体では7.8%で、副業をしている人の4.8%と同じく、農業・林業などを除いて働く人に占める割合です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

区分別に並べて、副業をしている人の割合と見比べると、次のようになります%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。表の「したい」は、他の仕事もしたい人の割合です。

| 働き方 | している | したい |
| --- | --- | --- |
| 全体 | 4.8% | 7.8% |
| 正規 | 2.5% | 7.7% |
| 非正規 | 7.2% | 8.4% |

%%総務省統計局「令和4年就業構造基本調査」(2022年10月1日現在)%%

非正規は、2つの割合が近い値です。ただ、2つの割合の差を「したいのに始められていない人の割合」と読むことはできません。2つの割合に同じ人が含まれるのかが、出典に書かれていないためです%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。5年前と比べると、正規の「したい」人の割合は2.4ポイント上がり、非正規は0.1ポイント下がっています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

また、この割合は「他の仕事もしたいと思っている人」の割合です。==実際に始められた人や、収入が得られた人の割合ではありません==。

辞めて他の仕事に変わりたい人は、この7.8%に入りません。入るのは、調査の就業希望の区分のうち、次の表の1行目だけです%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

| 調査での呼び名 | 調査での決まり | 7.8%に |
| --- | --- | --- |
| 追加就業希望者 | 現在就いている仕事を続けながら、他の仕事もしたいと思っている人 | 入る |
| 転職希望者 | 現在就いている仕事を辞めて、他の仕事に変わりたいと思っている人 | 入らない |
| 継続就業希望者 | 現在就いている仕事を今後も続けていきたいと思っている人のうち、追加就業希望者に当たらない人 | 入らない |
| 就業休止希望者 | 現在就いている仕事を辞めようと思っており、もう働く意思のない人 | 入らない |

つまり、7.8%は「続けながら」の人の割合で、辞めて変わりたい人の割合は含みません。

割合の話とは別に、副業を始めたあとの住民税の納め方が気になる人は、[副業の住民税の納め方｜申告書で選ぶ欄と、欄が出ないときの確かめ方](/posts/fukugyo-juminzei-choshu-hoho)で整理しています。

## 自分の区分の割合を、次に見返すときのメモの一行

副業をしている人の割合は、全体の値ではなく自分の働き方の区分の値で読み、県の値は別に見るのが、取り違えにくい読み方です。

- 母数と、調査での副業の数え方
- 勤め先での呼ばれ方で決まる、正規と非正規の区分
- 区分ごとの割合と、5年前からの差
- 働き方を問わない値としての県の割合
- 実際に始めた人の割合ではない、「他の仕事もしたい」人の割合

> 💡 NEVORAポイント
> 次に副業の話になったときは、==自分の区分の割合と住んでいる県の割合==を、別々の数字として書き留めてみてください。何の割合かも添えておくと、見返したときに取り違えません。「正規2.5%／東京都6.5%／正規のしたい人7.7%」のような形です。
