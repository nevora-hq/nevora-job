職場の昼休みや飲み会で、副業の話をほとんど聞いたことがない……そんな気がしませんか😓

周りにいないと、自分だけ出遅れているのか、始めたら浮くのかが気になりますよね。まだ始めてもいない自分は遅れているのかな、と感じている人もいると思います。

その答えは、令和4年(2022年)の国の調査にある割合を、自分の区分で見るとつかめます。

## 周りに副業の人がいない…実際の割合は何%？

周りに見えにくくても不思議ではない数字です。令和4年の調査では、副業がある人は305万人で、5年前より60万人増えました%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。ただ、農業・林業などを除いて働く人のうち4.8%、「正規の職員・従業員」では2.5%です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

契約社員やパートなどの「非正規の職員・従業員」では7.2%と、区分でかなり差があります。区分ごとの差は、上のグラフで見比べてみてください。

### 契約社員・パート・派遣は、どの数字で見ればいい？

まず、自分の働き方に近いのが正規と非正規のどちらかを決めておきましょう。勤務先で「正社員」と呼ばれているなら正規側、契約社員・パート・アルバイト・派遣などなら非正規側として、目安で見てください。

この調査の区分は、勤め先でどう呼ばれているかで分けられています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。「正社員」「一般職員」などの呼び名が正規で、パート・アルバイト・派遣社員・契約社員・嘱託・その他の6つをまとめたものが非正規です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

呼ばれ方ごとの行き先は、次の表のとおりです。

| 勤め先での呼ばれ方 | 調査での区分 |
| --- | --- |
| 正社員・一般職員 | 正規の職員・従業員 |
| パート・アルバイト(時間や日数は問わない) | 非正規の職員・従業員 |
| 派遣社員(労働者派遣事業所に雇われ、そこから派遣されて働く。港湾運送・建設・警備・医療関係の業務などは含めない) | 非正規の職員・従業員 |
| 契約社員(専門的な職種に従事させる目的で契約に基づき雇われ、雇用期間の定めがある) | 非正規の職員・従業員 |
| 嘱託(「嘱託職員」やそれに近い名称) | 非正規の職員・従業員 |
| 上のどれにも当たらない呼び名 | 非正規の職員・従業員(「その他」) |
| 会社などの役員(社長・取締役・監査役、団体の理事・監事など) | どちらにも入らない |
| 自営業主(個人経営の商店主・開業医・著述家など、自分で事業を営んでいる人) | どちらにも入らない |

呼び名で7つに分けられるのは「会社などの役員」以外の雇用者で、役員と自営業主は、この7つの対象に入っていません%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。正規2.5%・非正規7.2%は、役員以外の雇用者についての値で、自営業主やフリーランスの数字は、この部分には載っていません%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。調査でのフリーランスは、「実店舗がなく、雇人もいない自営業主又は一人社長であって、その仕事で収入を得る者」です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

「契約社員だけれど仕事の中身は正社員と同じだから、正規側で見る」と読み替えると、7.2%の行を見るところを、2.5%の行で見ることになります。==迷ったときは、普段の職場で自分がどう呼ばれているか==で選んでください。

> 💡 NEVORAポイント
> 調査上の区分と勤務先の呼び名は、ぴったり重ならない場合があります。迷ったら近い方を選んでください。

### 2つの仕事をしているとき、どちらが副業に数えられる？

調査での副業は、主な仕事以外に就いている仕事のことです%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。何が主な仕事になるかは、次の表の決まりで分けられています。

| 状況 | 主な仕事の決まり方 |
| --- | --- |
| 就業時間に差がある | 就業時間の長い方 |
| 収入に差がある | 収入の多い方 |
| 時間でも収入でも決められない | 回答者が主と考えている仕事 |

原文は「就業時間の長い方、又は収入の多い方」と書いているだけで、2つが食い違うときの優先順は書いていません%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。副業の数え方で迷うときは、勤め先での呼び名より先に、自分の2つの仕事のうち、時間が長いのはどちらか、収入が多いのはどちらかを書き出してみてください。

### あなたの県は何%？地方ごとに47都道府県を並べる

令和4年(2022年)10月1日現在の調査で、全国は4.8%、都道府県別では京都府が7.5%で最も高く、東京都が6.5%、和歌山県が5.6%と続きます%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。47都道府県のうち最も低いのは宮崎県の3.3%です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

地方ごとに、47都道府県の割合を並べると次のようになります%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

ここに載せたのは2022年の割合だけです。要約の表5-1には、2017年の割合と、5年での増減も載っています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

ここで見ている数字は、働き方を問わず、その県の副業者をまとめた値です。出典の表5-1には正規・非正規の内訳が載っていないため、「東京の正社員の割合」は読み取れません。県の数字を見て「東京は6.5%だから、正社員の2.5%は低すぎる」と読むと、働き方の違いと地域の違いを混ぜた比べ方になります。==地域の違いと働き方の違いは、別々に見る==ものです。

## 「出遅れた」と感じるとき、何と比べているか

昼休みに副業の話が出ないとき、周りに誰もいないと世の中でも少ない気がしてしまいますよね。比べる相手を、周りの人数から自分の区分の割合に置き換えると、見え方が変わります。

| 比べる相手 | 見えるもの |
| --- | --- |
| 周りの人数 | 自分の職場や知り合いの範囲で数えた人数 |
| 全体の4.8% | 農業・林業などを除いて働く人全体の値(自営業主なども含む) |
| 自分の区分の割合 | 正規なら2.5%、非正規なら7.2% |

比べるときの落とし穴は、全体の4.8%を自分の数字と見ることです。全体には、役員や自営業主など、雇われて働く人以外も含まれているためです%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。正社員なら2.5%、非正規なら7.2%と、==同じ区分どうしで比べる==と、見える位置が変わります。

5年前と比べると、副業者比率は全体で0.9ポイント、正規で0.6ポイント、非正規で1.3ポイント上がっています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。数字で見るかぎり、少数派ではあっても、どの区分も少しずつ増えている側です。

副業をしている人の人数が、2002年からどう動いてきたかは、[副業をしている人の数がいつから増えたかをまとめた記事](/posts/2026-09-11_fukugyo-data-de-miru-genjo)で整理しています。

> 💡 NEVORAポイント
> 比べる相手は、周りの人数ではなく==自分の区分の割合==です。

次に「出遅れかも」と感じたときは、^^自分の区分の割合を思い出してみましょう^^。

## あなたの働き方と引っかかりで、メモの1行は何になる？

区分と引っかかりを選ぶと、メモに書く数字と次にすることが1つに決まります。

「浮くかもしれない」という不安に、割合は答えを出しません。割合が示すのは、副業をしている人が全体の中でどれくらいかという点までで、職場の人の受け止め方は決めないからです。気になるのが「少数派でいること」なのか「周りに知られること」なのかで、確かめる先が変わります。^^次に浮く不安が出たとき、どちらが気になるのかを1行で書き分けてみてください^^。

### 気になるのは、少数派でいること？周りに知られること？

前者なら、自分の区分の割合のメモが手がかりになります。後者は、副業を周りに話すかどうかを自分で決める話で、手前に勤務先のルールの確認があります。

- 勤務先のルールを確かめる: 就業規則に副業の定めがあるか、禁止か許可制か届出制かを読む

> 💡 NEVORAポイント
> 「割合が小さいから、話したら浮く」と決めてしまうのは、==手順が逆==です。

## 「他の仕事もしたい」493万人は、どんな人の数なのか

「やりたい人の方が多いのでは」と気になるかもしれません。追加就業希望者は、現在の仕事を続けながら他の仕事もしたいと思っている人のことで、493万人です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

この記事では、305万人との差を人数として読むことはしません。上のグラフのように、副業がある人が4.8%、追加就業希望者が7.8%と、同じ母数に占める割合として並べて見てください%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

### 「したい」と「している」の差は、働き方で違う？

追加就業希望者の割合は、雇用形態別にみると、正規が7.7%、非正規が8.4%でした%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。副業をしている人の割合と並べたのが、次の表です。

| 働き方 | 副業をしている人の割合 | 他の仕事もしたい人の割合 |
| --- | --- | --- |
| 全体 | 4.8% | 7.8% |
| 正規の職員・従業員 | 2.5% | 7.7% |
| 非正規の職員・従業員 | 7.2% | 8.4% |

正規は7.7%と2.5%、非正規は8.4%と7.2%で、非正規の方が2つの割合が近い値です。2つの割合の差を「したいのに始められていない人の割合」と読むことはできません。要約には、2つの割合に同じ人が含まれるかの記述がないためです。

5年前と比べると、正規の「したい人」の割合は2.4ポイント上がり、非正規は0.1ポイント下がっています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

ただし、この割合は「他の仕事もしたいと思っている人」の割合です。==実際に始められた人や、収入が得られた人の割合ではありません==。

### 「転職したい」人は、この493万人に入る？

「他の仕事もしたい」と答えた人がどの数に入るかは、調査の就業希望の区分で決まっています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。この記事の7.8%に入るのは、次の表の1行目だけです。

| 調査での答え方(要約の定義) | 調査での呼び名 | 7.8%・493万人に |
| --- | --- | --- |
| 現在就いている仕事を続けながら、他の仕事もしたい | 追加就業希望者 | 入る |
| 現在就いている仕事を辞めて、他の仕事に変わりたい | 転職希望者 | 入らない(別の区分) |
| 現在就いている仕事を今後も続けたい(追加で他の仕事はしたいと思っていない) | 継続就業希望者 | 入らない(別の区分) |
| 現在就いている仕事を辞めようと思っており、もう働く意思がない | 就業休止希望者 | 入らない(別の区分) |

493万人は「続けながら」の人の数なので、辞めて変わりたい人の数は含みません。

副業を始めたあとの税金が気になる人は、[副業の住民税の徴収方法｜確定申告書での選び方と、選べないときの確かめ方](/posts/fukugyo-juminzei-choshu-hoho)で納め方を整理しています。

## 「出遅れかも」の日に、メモの1行へ入れる3つの数字

次に迷ったとき、どの数字をどこで見るかを決めておくと、落ち着いて判断しやすくなります✨

周りにいなくても、数字で見るかぎり、出遅れとは言えません。次に迷ったら、自分の区分の割合をメモで見てみてください。

### メモの1行に並べる3つの数字は、どう書き分ける？

3つの数字は、どれが何の割合かを一緒に書いておくと、あとで見返したときに取り違えません。書き方の例は「正規2.5%／東京都(全体)6.5%／正規のしたい人7.7%」のような形です。

地域の数字は働き方を問わない値なので、正規2.5%と足し引きしても、何の割合か分からない数字になります。==地域の数字と働き方の数字を足し引きしない==ことが、混ぜずに書くコツです。

- 副業をしている人は全体の4.8%で、正社員の区分では2.5%、非正規の区分では7.2%。
- 比べる相手は、周りの人数ではなく、自分の区分の割合と5年の増え方です。
- 追加就業希望者は、現在の仕事を続けながら他の仕事もしたい人のこと。
