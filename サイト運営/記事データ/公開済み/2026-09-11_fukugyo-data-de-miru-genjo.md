「副業をする人が増えている」という話を見かけて、それがいつからどれくらいの話なのか、気になったことはありませんか🤔

増えたと聞いても、ずっと増え続けてきたのか、最近のことなのかで、受け取り方は変わりますよね。副業を始めるか迷っている人も、数字をただ確かめたい人もいると思います。

国の調査には、5年おきの数字が20年分あります。並べて見ると、増え方が目立つ時期が見えてきます。

## 副業をしている人は増えている？2002〜2022年の人数を並べる

まず見たいのは、副業がある人の線が、ずっと上がり続けているのかどうかです。国の就業構造基本調査(5年ごとの調査)では、副業がある人は2002年が236万人、2007年が242万人、2012年が215万人、2017年が245万人、2022年が305万人でした%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。ここでの人数は、農業・林業などを除いて働く人のうち、主な仕事以外にも仕事がある人の数です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

追加就業希望者(いまの仕事を続けながら、他の仕事もしたい人)の線も、同じ図に並べてあります%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。こちらは2002年の315万人から2022年の493万人まで、時点ごとに増えています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

![朝の窓際で、紙のカレンダーに鉛筆で丸をつけている手元](/images/articles/fukugyo-data-body1.webp)

^^次に副業の人数が話題になったとき、どの年とどの年を比べた話かを思い出してみてください。^^

### 「副業」と「本業」は、どこで分かれる？調査の決め方

この調査で数えている「副業」の決め方は、同じPDFの付録2「用語の解説」にあります。

| 言葉 | 調査での決め方 |
| --- | --- |
| 有業者 | 仕事をしている人 |
| 副業 | 主な仕事以外の仕事 |

%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%

有業者は、ふだん収入を得ることを目的として仕事をしていて、調査日以降もしていくことになっている人、仕事は持っているが現在は休んでいる人です。仕事があったりなかったりして決められない場合は、おおむね1年間に30日以上仕事をしている場合です。

| 言葉 | 調査での決め方 |
| --- | --- |
| 主な仕事 | 時間か収入が多い方 |
| 副業が2つ以上 | 主なものを把握 |

%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%

主な仕事は、2つ以上の仕事をしている場合は、就業時間の長い方、または収入の多い方です。これらで決められないときは、回答者が主と考えている仕事です。

- ==数えているのは人==です。図の単位は万人で、副業の件数ではありません。
- **線引きは、この調査のもの**です。「自分は305万人に入るか」と「自分の会社で副業にあたるか」は、同じ基準で決まるとは限りません。会社の規則は就業規則や人事に、税金の扱いは税務署に確かめてみてください。

### 305万人は、全員に聞いた数字？

305万人は、全国の全員に聞いて数えた数ではありません。令和4年の調査は、令和2年国勢調査の調査区のうち総務大臣が指定した約3万4千調査区で行われ、その中から選ばれた約54万世帯の15歳以上の世帯員(約108万人)が対象でした%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。結果は、2022年10月1日現在の地域・男女・年齢階級などの人口に合わせて推定する方法で出されています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。
> 💡 NEVORAポイント
> 調査の対象・期日・推定の方法は、同じPDFの付録1「令和4年就業構造基本調査の概要」に書かれていて、==自分で読んで確かめられます==。

## いつから増えた？5時点の線を読む3つの見方

「いつから増えたのか」が気になるときは、線の動きを順に見ていきます。

### 2002〜2017年の4時点は「横ばい」と言っていい？

2002年から2017年までは、副業がある人は215万〜245万人の間で、増えたり減ったりしていました%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。2012年にいったん減り、2017年に戻っています。

> 💡 NEVORAポイント
> 5年おきの数字なので、==途中の年の動き==や、2012年から2017年のあいだに何があったかは、この調査では分かりません。


### 2022年の増加は、人数と割合を並べて見るとどうなる？

2022年は305万人で、5年前より60万人多くなりました%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。5年おきの数字を並べたとき、増え方が目立つのはこの直近の5年です。

人数と割合を、同じ年で並べると次のとおりです。割合は2007年以降の値があります%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

| 年 | 人数(万人) | 割合(%) |
| --- | --- | --- |
| 2007年 | 241.5 | 3.9 |
| 2012年 | 214.6 | 3.6 |
| 2017年 | 245.1 | 3.9 |
| 2022年 | 304.9 | 4.8 |

%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%

表の人数と割合は、どちらも副業がある人についての数字です。

割合で見ても、形は同じです。副業がある人が、農業・林業などを除いて働く人に占める割合は、2007年が3.9%、2012年が3.6%、2017年が3.9%、2022年が4.8%で、2022年は5年前より0.9ポイント上がっています%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。人数と割合のどちらで見ても、直近の5年が目立つ点は変わりません。増えた理由までは、この数字から読み取れません。

表の数字から自分で差を出すときは、==小数点第1位==まで入れて計算します。2017年から2022年の増加は、「60万人の増加」とも、59.8万人とも書かれます%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。304.9から245.1を引いても59.8なので、記事によって「60万人」「59.8万人」と見えても、元は同じ増加です。割合の差も同じで、PDFの本文のポイント差は四捨五入前の割合から算出されているため、PDFの統計表の割合から引いた結果と一致しないことがあります%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

> ⚠️ 注意
> 人数だけを見て「割合も上がった」と書くのは、読み違いのもとです。割合は働く人全体のうち副業がある人がどれだけかを表すので、人数が増えても、働く人全体がそれ以上に増えれば割合は上がりません。

### 折れ線の点と点のあいだは、読んでいい？

最初の図の線は、5つの点を直線で結んだものです。==点と点のあいだの線は、その年の実測値ではありません==。確かめ方は、図の点を数えることです。点は2002・2007・2012・2017・2022年の5つしかありません。

線の読み方は、次の2通りで結果が変わります。

| 読み方 | 点の扱い |
| --- | --- |
| 避ける | 点のあいだを読む |
| 使う | 点の数字だけを読む |

書き方の例は、避ける読み方なら「この5年は毎年少しずつ増えた」、使う読み方なら「2017年が245万人、2022年が305万人」です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

避ける読み方がなぜ危ないかというと、2017年から2022年の線が右上に伸びていても、5年のあいだの動きは数字から分かりません。ある年に大きく増えてその後は同じ水準だった場合も、2つの点を結ぶ線は同じ形になるからです。

「これからも増えるのか」が気になっている人は、次の見出しの診断で、見かけた数字の形を確かめてみてください。

## 「これからも増える？」この数字で言えること、言えないこと

### 数字は「いつ」「誰に」聞いたものか

「これからも増えるのかな」と気になったとき、手がかりになるのは、その数字がいつの時点のものかです。就業構造基本調査は1982年以降5年ごとに行われていて、令和4年の調査は2022年10月1日午前0時現在の数字です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。約54万世帯の15歳以上の世帯員を対象にした調査で、2022年より後の動きは、この調査からは読み取れません%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

調査の対象から除かれている人もいます。次の表の5つに当たる人です%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

| 調査の対象から除かれる人 |
| --- |
| 外国の外交団、領事団 |
| 外国の軍隊の軍人、軍属 |
| 自衛隊の居住者 |
| 刑が確定した被収容者 |
| 少年院などの在院者 |

それぞれの範囲は、次のとおりです。

- 外交団、領事団は、随員やその家族を含みます。
- 軍人、軍属は、それらの家族も含みます。
- 自衛隊は、営舎内または艦船内の居住者です。
- 刑が確定した被収容者は、刑務所、少年刑務所、拘置所の被収容者のうち、刑の確定している者です。
- 少年院などは、少年院、婦人補導院の在院者です。

「国民全体の中で305万人」のような書き方を見たときは、対象が==15歳以上の世帯員==だったことと照らして読んでみてください。%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%

だから「これから」は、==この数字だけでは決められません==。「増え続ける」と書かれた記事を見たときは、その数字がいつの調査までのものかを確かめてみてください。

![窓の外にオフィスビルが見える部屋で、ノートパソコンとノートが机に広げられているイラスト](/images/articles/fukugyo-data-honbun.webp)

### この数字から、副業の収入は分かる？

「副業の人は〇〇万人」という数字は、人数の数字で、副業の収入の金額を示すものではありません。調査事項の一覧(付録1の「調査事項」)を見ると、「主な仕事について」の項目には「年間収入」がありますが、「主な仕事以外の仕事について」の項目は、次の6つです%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。

| 副業について聞いている項目 |
| --- |
| 主な仕事以外の仕事の有無 |
| 従業上の地位・勤め先での呼称 |
| 勤め先の事業の内容 |
| 仕事の内容 |
| 就業の規則性 |
| 週間就業時間 |

### 「増え続ける」記事の数字を、元の調査まで辿る4手順

辿れるのは、記事に==調査名と年==が書かれている場合です。

### 別の調査の副業の数字と、並べて比べていい？

調査によって、仕事をしているかどうかのつかみ方が違います。

次の表は、この調査と、別の調査の就業の聞き方を比べたものです。

| 把握する期間 | 調査 |
| --- | --- |
| ふだんの状態 | 就業構造基本調査 |
| 月末1週間 | 国勢調査・労働力調査 |

どちらの調査も、仕事の有無を就業・不就業の状態で把握します。

### 493万人と305万人は、並べて引き算していい？

最初の図に並べた追加就業希望者の線は、副業がある人とは別の集計です。定義は「現在就いている仕事を続けながら、他の仕事もしたいと思っている人」で、副業をしていない人の数とは書かれていません%%出典:総務省統計局 令和4年就業構造基本調査 結果の要約%%。493万人と305万人の差は人数として読まず、それぞれの線の動きだけを見てください。凡例の線の名前と、PDFの注に書かれた定義を見比べて、==どの線がどの定義か==を確かめられます。

周りに副業をしている人が見当たらず、出遅れが気になる人は、[副業している人の割合は何%？｜働き方別・県別の数字で位置を探す](/posts/fukugyo-jinzu-data-hajimekata)で、自分の働き方に近い割合を整理しています。

## 次に「副業が急増」と見かけたとき、確かめる3点

増え方が目立つのは直近の5年で、その前は減ったり戻ったりでした。次に「急増」と見たら、人数か割合か、何年と何年か、いつの調査までかを確かめてみてください。

- 副業がある人は、2002年の236万人から2022年の305万人へと、5時点で上下しながら動いた
- 増え方が目立つのは直近の5年で、割合(3.9→3.6→3.9→4.8%)でも同じ形だった
- 数字は2022年10月1日までのもので、「これから」や希望者との差の人数までは言えない
