「副業OKの会社って、実際どのくらいあるんだろう」。検索して、数字が載っているページを探している人もいると思います🤔

数字が分かっても、自分の勤務先で話を出していいのかは、また別の話ですよね。まだ自分の悩みとして言葉にしていなくても、なんとなく気になっているだけ、という人もいるかもしれません。

ある企業調査では、他の会社に雇われる形の副業を認めているのは25.7%、認める予定を含めて31.9%でした%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。ただ、自社の答えは数字では決まらず、確かめられる場所があります。

## 調査の6つの答えを並べると、何が見えてくるのか

調査は、産業雇用安定センターが2023年6月から7月に、賛助会員企業等の7,609社に送ったアンケートで、回答は1,054件でした%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。この設問は、どの会社も答える形で、6つの選択肢を足すと100%になります%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。調査の対象は会社なので、数字は会社が答えた内容です%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。

### 自分の副業は、「雇われる形」と「自分で受ける形」のどちらか

「雇われる形」は、他社に従業員として雇用される形です%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。「自分で仕事を受ける形」は、自営業やフリーランスとして、委託契約や請負契約などで行う形です%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。自分の副業がどちらに近いかは、契約書や募集要項に書かれた契約の種類が手がかりになります。下の表で、見る言葉を確かめてみてください。

| 呼び方 | 契約の種類 |
|---|---|
| 雇われる形 | 「雇用」 |
| 受ける形 | 「業務委託」「請負」 |

他の会社に雇われる形の副業を==認めているのは25.7%==、今後認める予定が6.2%で、予定を含めると31.9%です%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。自分で仕事を受ける形(フリーランスや業務委託など)を認めているのは13.4%、今後認める予定が3.1%で、合わせて16.5%でした%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。一方で、「認める予定はない」が27.7%、「検討していない」が23.9%で、2つを合わせると約5割です%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。

自分で仕事を受ける形の副業を考えているなら、見る数字は25.7%ではなく13.4%の側です%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。この設問は2つの形を別々の選択肢にしているので、片方の割合をもう片方の目安にはできません。^^先に自分の副業の形を決めてから、その形の数字を読んでみてください^^。

### この数字は、日本の会社全体の数字と言えるのか

> ⚠️ 注意
> 回答企業の43.5%が製造業、39.0%が100人未満の会社です%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。日本の会社全体の割合とは言えず、2023年の調査なので、いまの割合も分かりません。

自分の勤務先の業種が、下の内訳のどこに入るかを見てみてください。

| 業種 | 回答企業に占める割合 |
|---|---|
| 製造業 | 43.5% |
| サービス業 | 13.7% |
| 商業(卸・小売業) | 11.1% |
| 建設業 | 7.5% |
| 運輸業 | 4.6% |
| 金融・保険業 | 2.9% |
| 情報通信業 | 2.8% |
| 不動産業 | 1.6% |
| 電気・ガス業 | 0.8% |
| 鉱業 | 0.1% |
| その他 | 11.5% |

割合の小さい業種(たとえば情報通信業の2.8%)は、回答した会社の数が少ないので、数社の違いで割合が動きやすくなります。勤務先の業種がこうした小さな割合の側なら、25.7%は出発点にとどめて、勤務先の公表と就業規則の確認を優先しましょう。

この数字を見て「うちの規模ではどうなんだろう」と思ったら、同じ調査の規模別の数字が手がかりになります。

## 自分の勤務先の規模だと、どの数字を見ればいいのか

### 勤務先は、5つの区分のどれに近いか

まず確かめたいのは、自分の勤務先がどの規模の区分に近いかです。^^近い区分を1枚選んでみてください^^。区分の名前は資料のままで、100人未満の次が「300人未満」、その次が「1000人未満」と続きます。カードには、同じ6つの選択肢の割合が並んでいます。

調査の対象は会社なので、区分は勤務先の会社の従業員数で選びます。従業員数が会社の公表や採用ページに載っていれば、そこで決めてください。100人、300人、1000人、5000人の前後で迷うときは、隣り合う2つの区分の数字を見比べます。差が小さければ、どちらを選んでも読み違えは小さく済みます。

### 雇われる形の割合は、規模が大きいほど高くなるのか

雇われる形で認めている割合を見ると、5000人以上は38.1%、100人未満は23.4%です%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。

| 区分 | 認める | 予定 | 合計 |
|---|---|---|---|
| 100人未満 | 23.4% | 6.8% | 30.2% |
| 300人未満 | 23.0% | 5.5% | 28.5% |
| 1000人未満 | 30.2% | 3.9% | 34.1% |
| 5000人未満 | 24.5% | 7.5% | 32.0% |
| 5000人以上 | 38.1% | 8.3% | 46.4% |

表の「認める」は「認めている」、「合計」は同じ区分の「認めている」と「認める予定」を足した数字です%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。5000人以上がいちばん高い一方で、順番は一直線ではありません。100人未満(23.4%)より300人未満(23.0%)のほうが低く、1000人未満(30.2%)より5000人未満(24.5%)のほうが低くなっています%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。

大きい会社のほうが認めやすいはずと考えて、自分の区分ではなく5000人以上の38.1%を基準にしてしまうと、自分の勤務先より高い数字を見ることになります💦 隣の区分の数字は、見比べるためだけに見ます。

### 78.6%は、雇われる形だけの割合なのか

| 5000人以上 | 割合 |
|---|---|
| 雇われる形を認めている | 38.1% |
| 雇われる形を認める予定 | 8.3% |
| 受ける形を認めている | 27.4% |
| 受ける形を認める予定 | 4.8% |
| 4つの合計 | 78.6% |
| うち雇われる形だけ(足した値) | 46.4% |

5000人以上では、雇われる形と自分で受ける形のどちらかを認めている、または認める予定の会社を4つ合わせて78.6%とする整理もあり、この78.6%は雇われる形だけの数字ではありません%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。
「約8割」とだけ見かけて雇われる形の話だと受け取ると、高く見積もりすぎてしまいます💦 4つの内訳を足し直して、自分の副業の形の分だけを取り出してみてください。

### 「検討していない」は、規模でどれだけ違うのか

「検討していない」は、5000人以上で6.0%、100人未満で31.6%を占めます%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。表の「予定なし」は「認める予定はない」、「未検討」は「検討していない」です。

| 区分 | 予定なし | 未検討 |
|---|---|---|
| 100人未満 | 26.3% | 31.6% |
| 300人未満 | 35.0% | 23.7% |
| 1000人未満 | 28.5% | 19.0% |
| 5000人未満 | 22.6% | 17.0% |
| 5000人以上 | 15.5% | 6.0% |

「検討していない」は、区分が大きくなるにつれて31.6%、23.7%、19.0%、17.0%、6.0%と順に下がっています%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。「認める予定はない」は300人未満の35.0%がいちばん高く、こちらは一直線には並びません%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。

選択肢の名前どおりに読むと、「認める予定はない」は認めない方向で答えた会社、「検討していない」はまだ検討していない会社です。勤務先が小さな会社なら、公表が見当たらないだけで「禁止だ」と決めてしまうのは早いかもしれません。次の節の順で、就業規則の置き場所を聞くところまで進めてみてください。

### 回答の少ない区分の数字は、どこまで信じていいのか

ただ、区分ごとの回答数は資料に載っていません。回答企業のうち5000人以上は8.0%、100人未満は39.0%を占めるので%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%、数字は幅をもって見てください。

| 区分 | 回答企業の割合 |
|---|---|
| 100人未満 | 39.0% |
| 300人未満 | 26.0% |
| 1000人未満 | 17.0% |
| 5000人未満 | 10.1% |
| 5000人以上 | 8.0% |

占める割合が小さい区分ほど、回答した会社の数が少ないので、数社の違いで割合が動きます。自分の区分が5000人未満(10.1%)や5000人以上(8.0%)なら、隣の区分の数字も並べて読み、一方の数字だけで言い切らないようにしてください。メモには、雇われる形で認めている割合を1つ書いてみてください。

> 💡 NEVORAポイント
> ==この割合は、自社の合否の判定ではありません==。自分の規模の数字は、確かめる前の出発点として使いましょう。

数字が分かっても、肝心の自社が認めているかは、カードを見ただけでは分かりませんよね。次の2問で、自社の確認がどこまで進んでいるかを確かめてみてください。

## 自社が認めているか、どこで確かめるのか

診断のどの結果になっても、確かめる場所は2つです。

### 公表の文面は、2つの型のどちらに近いか

1つ目は会社の公表で、副業・兼業を許容しているか、条件つきならその条件を、企業が自社のホームページなどで公表することが推奨されています%%出典:厚生労働省「『副業・兼業の促進に関するガイドライン』Q&A」%%。

公表の記載例は、条件を設けない型と、条件つきの型の2つに分かれます%%出典:厚生労働省「『副業・兼業の促進に関するガイドライン』Q&A」%%。条件を設けない型は、副業・兼業を条件を設けることなく認める文面です。条件つきの型は、原則は認めるが、長時間労働の回避をはじめとする安全への配慮、秘密を守ること、同業での競合を避けること、誠実に働くことが難しくなるおそれがある場合は認めない、という文面です%%出典:厚生労働省「『副業・兼業の促進に関するガイドライン』Q&A」%%。
条件つきの型に近い文面を見つけたら、^^「ただし」より後ろの文を、そのまま手帳に写してください^^。「原則認めています」だけを写すと、あとで自分の副業が条件に当たるかを確かめるときに、手がかりが残りません。

見つけた文面がどちらに近いかは、下の表の言葉の有無が手がかりになります。

| 型 | 手がかりの言葉 |
|---|---|
| 条件なし | 「条件を設けることなく」 |
| 条件つき | 「原則」「ただし」 |

### 公表は、自分で受ける形の副業にも触れているか

公表の対象は、他の会社に雇われる形が例に挙がっています%%出典:厚生労働省「『副業・兼業の促進に関するガイドライン』Q&A」%%。そのほか、事業主として行う副業や、請負や委託の契約で仕事を受ける副業(フリーランス、独立、起業なども含まれます)も、公表の対象として考えられます%%出典:厚生労働省「『副業・兼業の促進に関するガイドライン』Q&A」%%。公表は推奨されているものなので、文面がどこまでの形に触れているかは、会社ごとに違うかもしれません。

「副業を認めています」の一文だけを見て、自分で受ける形も含まれると受け取ってしまうと、あとで食い違うおそれがあります。文面に次の言葉があるかを探してください。

| 見つけた言葉 | 触れている形 |
|---|---|
| 「フリーランス」 | 受ける形 |
| 「業務委託」 | 受ける形 |
| 「請負」 | 受ける形 |
| 「独立」「起業」 | 事業主の形 |
| 言葉が無い | 記載なし |

言葉が見つかったときは、その言葉と、条件があればその条件をメモします。言葉が無いときは、メモに「受ける形の記載なし」と書き、2つ目の就業規則の副業の欄で確かめます。

### 公表が見つからないとき、ほかに探す場所はあるか

会社案内や採用パンフレットでの公表も例に挙がっています%%出典:厚生労働省「『副業・兼業の促進に関するガイドライン』Q&A」%%。推奨なので、すべての会社が出しているとは限りません。

グループ企業でも、各社が個別に副業・兼業の就業規則を定めている場合は、公表も会社ごとに行うことが望まれます%%出典:厚生労働省「『副業・兼業の促進に関するガイドライン』Q&A」%%。親会社やグループ全体のページに載っていなくても、無いと決めずに、自分を雇っている会社の名前のページまで見に行きましょう。給与明細や雇用契約書に書かれた会社名で探せば、見るページを取り違えにくくなります。

### 就業規則に副業の欄が見当たらないとき、どう動くか

2つ目は、就業規則の副業の欄です。同じ調査では、副業・兼業について「就業規則」に明記している会社が56.3%、「就業規則以外の規定」に明記している会社が6.8%で、明記していない会社が36.9%でした%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。

![書類の束とカレンダーを前に、ノートパソコンで労務管理の実務に向き合う担当者のイラスト](/images/articles/fukugyo-kigyo-ninchi-romu.webp)

「就業規則以外の規定」に明記している会社があるので、就業規則に副業の欄が見当たらなくても、別の規定に決まりがある場合があります%%出典:産業雇用安定センター「従業員の『副業・兼業』に関するアンケート調査結果の概要」(厚生労働省サイト掲載)%%。「副業」の語で見つからないときは、「兼業」の語でも探してみてください。欄が見当たらないことを、許可の印と受け取っても、禁止の印と受け取っても、確かめる前の決めつけになります。メモには「副業欄なし」と書くだけにして、結論は出さないでください。

就業規則が見当たらないときは、^^最新の就業規則の置き場所を、人事・総務に聞いてみてください^^。「最新の就業規則を見たい」とだけ伝えれば、副業の話はその場では出さなくても大丈夫です。書かれ方で迷ったら、勤務先の人事・総務に確かめましょう。

条文が見つかったら、書かれ方の見分け方は[就業規則に副業禁止とあったら｜会社が止められる場面の見分け方](/posts/fukugyo-shugyokisoku-kakunin)で整理しています。

## メモの1行に、何を残せば次に迷わないのか

雇われる形の副業を認めている会社は、この調査で25.7%、認める予定を含めて31.9%でしたが、自社の答えは数字では決まらず、会社の公表と就業規則の副業の欄で確かめることになります。

- 雇われる形で認めているのは25.7%、予定を含めて31.9%で、日本の会社全体の割合とは言えません。
- 見る数字は、全体よりも、自分の勤務先に近い規模の区分のものです。
- 自社の答えは、会社の公表と就業規則の副業の欄に出ているかで確かめましょう。
- 確かめた結果は、規模の数字といっしょに、1行のメモに残せば完了です。

### メモの1行に、何を書いて何を書かないか

公表は、副業・兼業が許容される条件に変更があった場合に、速やかに更新されることが望まれています%%出典:厚生労働省「『副業・兼業の促進に関するガイドライン』Q&A」%%。見た日付が残っていれば、次に開いたときに、文面が変わっていないかを見直せます。

メモの数字には、2023年の調査・回答1,054社を添えます。公表の文面は、条件つきなら「ただし」のあとまで写し、副業欄は見た就業規則の置き場所も残します。

| 書く | 書かない |
|---|---|
| 区分の名前 | 大きい会社 |
| 調査の年と対象 | 年を外した割合 |
| 見た日付 | たぶんOK |
| 副業欄の有無 | 欄なしの推測 |
