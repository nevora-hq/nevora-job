副業で業務委託の仕事を受けていると、「フリーランス法」という言葉を目にすることがありませんか？ 調べても、会社に雇われている自分の副業の依頼にまで関わる話なのか、読んだだけでは分かりにくいですよね💦

依頼主が個人のときも、会社のときも、クラウドソーシングを通したときも、当てはまり方は変わってきます。副業の受注が対象になる入口、条件の明示や支払期日の決まり、手元の依頼で確かめる先まで、詳しく見ていきましょう。

## 副業の受注でも、フリーランス法の対象になるのか

フリーランス法は、2024年11月1日に施行された法律です%%出典:厚生労働省 栃木労働局 令和6年11月1日からフリーランス・事業者間取引適正化等法がスタートしました%%。副業で受けた仕事が対象になるかを見る入口は3つあります。

### 3つの入口は、手元の依頼でどう見分ける？

1つめは、依頼主が事業として出している依頼であることです%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。2つめは、物の制作や、文章・プログラム・デザインなどの成果物づくり、あるいは作業そのものを任される業務委託の形で受けていることです%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。3つめは、自分が従業員を使わず、1人で受けている点です%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

1つめの事業として出している依頼かどうかは、依頼主が個人のとき、事業者としての契約か消費者としての契約かを、契約を結ぶ段階で見ます%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。業務の内容が事業のためだと外から見て明らかか、明らかでなければ、消費者として受けることが想定しにくい内容かが目安です%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。純粋に無償の行為のための依頼は、事業のための委託にあたりません%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

2つめの業務委託にあたるかどうかは、仕様や内容を指定された依頼かどうかで、次のように分かれます%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

| 依頼の中身 | 業務委託か |
|---|---|
| 仕様を指定した作成・作業 | あたる |
| 出来上がった物を売るだけ | 原則あたらない |
| 一部でも依頼主向けに加工 | あたる |

3つめの従業員を使わずという条件で、誰を従業員に数えるのでしょうか。

### 「従業員を使う」に数えるのは、誰？

数えるのは、受ける仕事の事業ではなく、個人または法人として従業員を使っているかどうかで、数える時点は業務委託をした時点です%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

> 💡 NEVORAポイント
> 「従業員を使う」とは、週の所定労働時間が20時間以上で、31日以上雇う見込みの人を雇っていることです%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

短時間の一時雇用や同居の親族だけの場合など、数える相手と数えない相手は、次の表のとおりです。

| 相手 | 数え方 |
|---|---|
| 短時間・短期間の一時雇用 | 数えない |
| 同居の親族だけ | 数えない |
| 雇用関係のない手伝い | 数えない |
| 条件を満たす派遣労働者 | 数える |
| ほかの事業の従業員 | 数える |

同居の親族は、居住と生計が同一の親族を指します%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

### 会社員でも、副業の仕事は入口に立てるのか

会社に雇われている人でも、副業で他の事業者から業務委託を受けているなら、その副業の範囲では対象になる場合があります%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

> ⚠️ 注意
> 契約書に「業務委託」と書かれていても、働き方の実態が労働者と認められる依頼主との関係では、この法律の対象にならず、労働基準法などの労働関係の法令が適用されます%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。契約書の名前だけで決めず、==仕事の任され方==を見ましょう。

次に依頼を受けるときは、契約書の名前にかかわらず、仕事をどう任されているかを見てみてください。

## 文面で条件を示す依頼主と、60日以内に払う依頼主の分かれ目

依頼主が事業として業務委託をしたなら、従業員がいなくても、条件を文面で示すことが必要です%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。一方で、60日以内の支払期日が付くのは、従業員を使っている依頼主か、従業員がいなくても役員が2人以上いる法人の依頼主です%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。この2つを、以下では従業員か複数の役員がいる依頼主と呼びます。依頼主の区分ごとに何が付くかは、次の図で並べて確かめてみてください。

### 条件の示し方は、メールやチャットでもいい？

条件は、依頼主が業務委託をしたら直ちに、書面か、メールやチャットなどの電磁的な方法で示す必要があり、口頭だけでは足りません%%出典:公正取引委員会 フリーランス法特設サイト%%。書面と電磁的方法のどちらで示すかは、依頼主が選べます%%出典:公正取引委員会 フリーランス法特設サイト%%。示し方ごとの扱いは、次の表のとおりです%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

| 示し方 | 扱い |
|---|---|
| 書面 | 認められる |
| メール・チャット・SMS | 認められる |
| SNSなどのメッセージ | 認められる |
| 明示事項のURL入りメッセージ | 認められる |
| 口頭だけ | 認められない |

特にクラウドサービスなどを使う場合は、メッセージが削除されたり、環境が変わって見られなくなったりすることがあります%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。そのため、スクリーンショットなどで、依頼主と自分の双方が残しておくことが望まれます%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。メールなどで示されたあとでも、条件を書いた書面の交付を求めれば、依頼主は遅滞なく交付しなければなりません。ただし、受注側の保護に支障がない場合として公正取引委員会規則で定める場合は除かれます%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。

### 受け取った日から60日は、どう数える？

従業員か複数の役員がいる依頼主は、納品物を受け取った日から60日以内の、できる限り短い期間に支払期日を決めて、その日までに払う必要があります%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。

![夜の机の上に置かれたノートパソコンと卓上カレンダー、ノート](/images/articles/fukugyo-freelance-ho-body1.webp)

数え始めは、納品物を受け取った日で、作業なら提供を受けた日です。その日も1日目に数えます%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。メールなどで成果物を受け取る場合の数え始めは、依頼主のパソコンなどに記録された時点です%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

> ⚠️ 注意
> 従業員か複数の役員がいる依頼主の契約書に60日を超える支払期日が書かれていても、依頼主が納品物を受け取った日から60日を経過する日が支払期日とみなされます%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。支払期日の定めがないときは、受け取った日が支払期日とみなされます%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。契約書の日付ではなく、==受け取った日から数えた日付==を確かめましょう。

受注側に原因があって、報酬を払う前にやり直しをする場合は、やり直したあとの物を受け取った日が数え始めになります。役務の提供なら、役務を提供した日です%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

### 元の発注者から回ってきた仕事は、30日になる？

元の発注者から受けた仕事を、さらに自分に回してもらう再委託では、条件を満たすと、元の支払期日から30日以内という別の定めが使われます%%出典:公正取引委員会 フリーランス法特設サイト%%。30日の別の定めが使えるのは、依頼主が条件の明示で、ほかの事項に加えて、次の3つを示した場合だけです%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律、公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

| 示す事項 |
|---|
| 再委託であること |
| 元の発注者の名称 |
| 元の仕事の代金の支払期日 |

手元の文面にこの3つが書かれていなければ、30日の別の定めは使えず、受け取った日から60日以内の線のままです。書かれているときは、30日の別の定めが関わる可能性があります%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。ここでいう元の支払期日は、元の発注者が代金を払う日として定められた期日で、実際に払われた日ではありません%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

### 委託が1か月以上だと、何が加わる？

従業員か複数の役員がいる依頼主が、委託が1か月以上のときに禁止される行為は、次の7つです%%出典:公正取引委員会 フリーランス法特設サイト%%。

| 禁止される行為 |
|---|
| 受領拒否 |
| 報酬の減額 |
| 返品 |
| 買いたたき |
| 購入・利用強制 |
| 不当な経済上の利益の提供要請 |
| 不当な給付内容の変更・やり直し |

受領拒否・報酬の減額・返品・不当な給付内容の変更・やり直しは、受注側に落ち度がないのに行う場合が対象です%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。役務の提供を頼まれる仕事では、受領拒否と返品は、禁止の対象から除かれます%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。

1か月以上かどうかは、単一の業務委託では、業務委託をした日を1日目として、示された受領期日や契約の終了日のうち遅い日までを数えます%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。従業員か複数の役員がいる依頼主が、報酬を振り込むときの手数料を、合意の有無にかかわらず受注側に負担させて、報酬の額から差し引くことも、委託が1か月以上なら報酬の減額として問題になります%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

とはいえ、依頼主の従業員や役員の数は、外からは分かりにくいですよね。手元の依頼では、何を見れば確かめる先を決められるのでしょうか。

## 自分の依頼はどの形か、クラウドソーシングで相手が見えないとき

依頼主の従業員や役員の数は分からなくても、手元の依頼で見えるものはあります。内容・報酬額・支払期日が文面に残っているかと、その依頼をどんな形で受けたかです。次の2問で、確かめる先を1つに決めてみてください。

クラウドソーシングを通して受けた場合は、誰が業務委託をする事業者になるかが、サイトの関わり方しだいです。仲介だけで事務手続きの代行にとどまるなら依頼主、実質的に業務委託をしているならサイトの運営が、その事業者に当たります%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。^^利用規約の契約の相手の項目を、自分の目で開いて確かめてみてください^^。

入口を選び直すなら、[副業の仕事はどこから来る？｜最初の1件の前に見落としやすい点](/posts/2026-10-02_fukugyo-shigoto-nyushu-keiro)も参考になります。

## 入金が遅れているとき、先に手元で揃えるもの

期日を過ぎても入金がないとき、60日の話を手元の日付でどう確かめればよいのでしょうか。先に手元で揃えるのは、納品を受け取ってもらった日、約束の支払期日、実際の入金日の3つです。

![窓際の机で、白いノートに箇条書きを書いている手元と、画面を消したスマートフォン](/images/articles/fukugyo-freelance-ho-body2.webp)

### 入金予定日を過ぎたら、まず見る3つの日付は？

事業として出している依頼で、従業員か複数の役員がいる依頼主なら、支払期日は受け取った日から60日以内に決める必要があります%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。再委託では、条件を満たすと、元の支払期日から30日以内という別の定めが使われます%%出典:公正取引委員会 フリーランス法特設サイト%%。従業員も2人以上の役員もいない依頼主には、この60日以内の支払期日の義務は当たりません%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

60日の義務が関わる依頼主なら、請求書をまだ出していなくても、定めた支払期日までに報酬を払う必要があります%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。請求書を出していないことは、受注側に原因があるとは扱われません%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

> ⚠️ 注意
> 自分が伝えた口座番号が誤っていて、依頼主が支払期日までに払い込んでいても受け取れなかったときは、受注側に原因があると扱われる例です%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。その場合は、その原因がなくなった日から60日以内に払う決まりで、再委託で30日の別の定めが使われているときは30日以内です%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。==口座番号==は、伝える前に見直しておきましょう。

### 依頼主へ送る一文は、どう書く？

日付がそろったら、依頼主へ事実だけを伝えます。たとえば「納品は◯日、お支払いは◯日とお聞きしていますが、入金を確認できていません」のように、^^日付を並べた一文を、メールかチャットで送ってみてください^^。

> ⚠️ 注意
> 依頼主の従業員や役員の数は外から分かりにくいので、「法律違反だ」と決めつけず、==日付だけを伝える==のが安全です。

### 支払いが遅れて、個人では抱えきれないとき

条件が文面に残らない、支払いが遅れるなど、個人では解決できない状態が続くなら、フリーランス・トラブル110番という、弁護士に無料で相談できる窓口があります%%出典:公正取引委員会 フリーランス法特設サイト%%。法の違反と思われるときは、公正取引委員会の違反申出窓口もあります%%出典:公正取引委員会 フリーランス法特設サイト%%。

> ⚠️ 注意
> 公正取引委員会または中小企業庁長官に違反を申し出ても、そのことを理由に、取引の数量の削減や取引の停止などの不利益な取扱いをしてはならないと、法律に定められています%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。

手元の準備は、次のチェックで確かめてみてください。

## 次の依頼の前に、依頼主へ文面で送る4項目

副業の依頼でも、従業員を使わず1人で受けているならフリーランス法が関わる場合があり、条件の文面化は従業員のいない事業者の依頼主にも求められ、60日以内の支払期日は従業員か複数の役員がいる依頼主の義務、と分けて見ると、確かめる先が決まります。

- 1人で受ける副業の依頼が、対象になる場合がある入口
- 事業者の依頼主なら、従業員がいなくても必要な条件の明示
- 受け取った日から数える60日以内の支払期日と、義務を負う依頼主の範囲
- クラウドソーシングでの契約の相手と、利用規約での確かめ先

### 4項目は、返信メールにどう並べる？

内容・報酬額・支払期日・納期の4項目を先に文面にしておくと、あとで日付を並べる手間が減ります。返信メールの作例は、次の表のとおりです。

| 項目 | 書き方の例 |
|---|---|
| 内容 | ◯◯の制作 |
| 報酬額 | ◯円 |
| 支払期日 | ◯月◯日 |
| 納期 | ◯月◯日 |

### 4項目のほかに、文面に入る事項は？

依頼主が示す事項には、4項目のほかに、次のものがあります。示すことが求められるのは、委託内容を明確にして、当事者間のトラブルを未然に防ぐためです%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。

| 事項 | 内容 |
|---|---|
| 名称 | 依頼主と自分 |
| 業務委託をした日 | 合意した日 |
| 場所 | 給付・役務を受け取る所 |
| 検査完了日 | 検査をする場合 |
| 支払方法 | 現金以外で払う場合 |

名称は、当事者どうしで特定できれば、ハンドルネームやペンネームでも書けます%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。「業務委託をした日」は、仕事を引き受けることに合意した日で、作業に着手する日とは別です%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。返信メールには、着手日ではなく合意した日を書くと、日付が食い違いにくくなります。

### 報酬がまだ決まらない依頼は、どう扱う？

報酬の額などが、業務委託をした時点でまだ決められない依頼もあります。決められない正当な理由がある事項は、その時点では示さなくてよく、内容が定まった後に直ちに、書面か電磁的方法で示す必要があります%%出典:e-Gov法令検索 特定受託事業者に係る取引の適正化等に関する法律%%。

> ⚠️ 注意
> 決められない正当な理由とは、取引の性質上、その時点では内容を決められないと客観的に認められる場合で、たとえば、ソフトウェアの作成の依頼で、最終ユーザーが求める仕様が確定しておらず、委託内容を決められない場合があります%%出典:公正取引委員会 フリーランス・事業者間取引適正化等法 Q&A%%。正当な理由がないのに「あとで決めます」とされた事項は、この例外にあたりません。
