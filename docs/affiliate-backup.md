# アフィリエイトリンク削除台帳

## 背景・方針

AdSense審査を最優先するため、審査リスクとして残す意味のない既存アフィリエイトリンクを全件削除するときは、この台帳に記録する(詳細方針はユーザー指示を参照)。

- 削除対象は `サイト運営\記事データ\確定稿` / `公開済み` 側の記事frontmatter(`affiliateLinks:`)および、本文Markdown中で当該URLに直接張られていたリンク(`[label](URL)`、多くは末尾に `(PR)` 表記付き)。
- 表示機構(`lib/posts.js` の `embedAffiliateBanners`/`renderAffiliateBannerHtml`、`components/AffiliateBanner.js`、`pages/posts/[slug].js` の `post.affiliateLinks?.length > 0` 条件付き注意書き)は**削除しない**。frontmatterの `affiliateLinks` が空/未指定なら何も表示されない設計のため、本ページの情報を**同じキー・URL・画像URLでfrontmatterに復元するだけ**で再掲載できる。
- 各記事本文中の「※本記事にはアフィリエイト広告(PR)を含みます。当サイトを経由して...」という手書きの注意書き段落も、実態(PRリンクなし)に合わせて削除する。貼り直し時はこの一文も復元すること。
- `pages/compare.js` は `items`(=全記事の `affiliateLinks` を集約したもの)が0件の間、ページ上部の固定注意書きを出さない(`items.length > 0` の条件付き表示)。リンクを復元すれば自動的に再表示される。

削除したら、次の形で書く。

| 記事(確定稿/公開済み) | 商品名・サービス名 | 元URL | 画像URL | ASP |
|---|---|---|---|---|
| (記録なし) | | | | |

## 追加削除(サイトレベル整合性監査などで発覚したもの)

追加で見つかったときは、次の形で書く。

| 記事 | 商品名・サービス名 | 元URL | 画像URL | ASP |
|---|---|---|---|---|
| (記録なし) | | | | |

| 記事 | 内容 | 備考 |
|---|---|---|
| (記録なし) | | |

参考: 元から `affiliateLinks: []`(空)で、削除作業が不要だった記事もここに書く(記録なし)。

## 教訓

一括削除の対象範囲(`確定稿`/`公開済み`)に含まれていない`公開待ち`・`非公開アーカイブ`フォルダ内の同名記事の**別ファイル(重複)**や、別バージョン(リライト版)の記事に、アフィリエイトリンク(実在ASPリンクのほか、`example.com` のプレースホルダーURL・リンク挿入用HTMLコメント・PR表記を含む)が残ることがある。

**教訓**: 同一記事が複数フォルダ(確定稿/公開済み/公開待ち/非公開アーカイブ)に重複して存在しうるため、一括処理の対象範囲は「フォルダ」ではなく「記事(ファイル名)」単位で洗い出すこと。削除後は、全フォルダを対象にアフィリエイトリンクパターン(`a8.net`・`moshimo.com`等のASPドメイン、`affiliateLinks:`、PR表記文言)を再検索する。プレースホルダーURLでも、全カット方針のときは実在有無を問わず記事にアフィリエイト言及自体を残さない。

副業の題材では、ASPのドメインが出典URL(例: ASPの公式ヘルプ)として `sources` に載ることがある。再検索でヒットしても、`sources` の出典URLはアフィリエイトリンクではないので削除しない(リンク先が成果報酬の広告リンクかどうかで見分ける)。

## 貼り直し時の手順

1. 上表のURL・画像URLは提携解消の可能性があるため、貼り直し前にA8.net/もしもアフィリエイト等のASP管理画面でリンクの有効性を再確認すること(URLをそのまま使い回さない)。
2. 該当記事のfrontmatterに `affiliateLinks:` を復元する(`docs/citation-format.md`と同様、`lib/posts.js`の`normalizeAffiliateLinks`が`label`/`url`/`image`キーを受け付ける)。
3. 本文中の該当箇所に `[商品名](URL)` の形でリンクを再設置する(`embedAffiliateBanners`は本文中の`href`一致でバナーを自動挿入するため、frontmatterと本文の両方にURLが必要)。
4. 「※本記事にはアフィリエイト広告(PR)を含みます。」等の注意書きは、`pages/posts/[slug].js`側で`post.affiliateLinks?.length > 0`のとき自動表示されるため、本文に手書きで再度追加する必要は**ない**(手書きの重複表示を避けるため)。
5. `pages/compare.js`は全記事の`affiliateLinks`を自動集約するため、追加の手作業は不要。
6. 副業の題材では、リンク先のサービス(スクール・クラウドソーシング・ASP・証券口座・ポイントサイト等)について、本文で収入・成果を保証・断定する書き方(「誰でも稼げる」「必ず月◯万円」等)をしない(景品表示法の優良誤認〔第5条第1号、内容についての表示〕)。料金・報酬条件・手数料・「初期費用無料」「今だけ」などの取引条件を、実際より有利に見せる表示もしない(同法の有利誤認〔第5条第2号、価格その他の取引条件についての表示〕)。広告であることが分かる表示(ステルスマーケティング告示)と、投資商品では元本保証を連想させる表現・特定商品の推奨に見える表現を避けることを、貼り直し後の法務チェックで確かめる。
