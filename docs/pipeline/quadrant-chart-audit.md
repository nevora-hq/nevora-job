# quadrantチャート誤読リスク監査

対象: `type: "quadrant"`チャートを持つ全記事(`確定稿`+`公開済み`)。

背景: 軸の値が高いほど悪い(費用など)のに、高い方に◎がつくと「優れている」と誤読されるリスクがある。`lib/posts.js`の`renderQuadrantChartHtml`は、◎○△の評価記号を廃止し、中立的な高低表現(「高い/中程度/低い」)をデフォルトにしている(`docs/CONTRIBUTING.md` §20参照)。この変更により記号由来の誤読リスクは全記事で自動的に解消される。

監査では、軸の意味が「高い=悪い(費用・価格など)」であるため、レンダラーが中立語になっても文言(「高い/中程度/低い」)だけでは実感に合わない可能性がある記事を一覧にする。**修正はユーザーの確認後に行う(本監査は報告のみ)。**

副業の題材では、高い=悪い軸の例は、初期費用・月額費用・学習にかかる時間・手数料・作業時間・リスクの大きさなど。両軸が「高い=好ましい」か、良し悪しを伴わない特性(例: 在宅でできる度合い・始めやすさ・単価の幅)なら追加対応は不要で、軸ラベルに方向の注記(低い←→高い)があれば足りる。軸に「稼ぎやすさ」「収入の大きさ」を置くと収入・成果の断定に見えやすいので、そうした軸名は避け、「単価の目安の幅」など出典で裏付けられる言い方にする。

## 誤読リスクあり(費用・価格軸で「高い=悪い」の意味を持つ)

- `note` フィールドを持つチャート: レンダラーの中立化(◎○△→「高い/中程度/低い」)が適用される。個別の`xNote`/`yNote`(具体的な文言)を追加すればより親切だが、誤読リスクという観点では必須ではない。
- `note` が無く `source` だけを持つチャート: フォールバック表に座標の生数値がそのまま表示される(測定値のように見える別の課題。優先度: 低。`note` 追加の要否はユーザー判断)。
