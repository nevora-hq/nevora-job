# 運営者(依頼者)の決定の台帳

作成: 2026-11-19(元サイトの「記事品質ルール一式」の部品1・補遺1を取り入れた作業)。2026-11-20 に、依頼者の回答(1〜9)を反映して更新した(第1節の2026-11-20の行、第2節・第4節・第6節・第7節)。規則本文は `.claude/agents/writer.md` が正で、この台帳は「誰が・いつ・何を決めたか」「どの程度確かか」だけを置く。規則の中身はここに写さず、反映先を書く。

## 0. 使い方

- 3つの層を混ぜない(元サイトの台帳と同じ)。
  - **A**: 依頼者(運営者)自身の発言の原文が、記録で確認できたもの
  - **A-記録**: 日付つきの依頼者の決定と文書が明記しているが、原文は未確認のもの。有効として扱うが、新しい合否の基準の根拠にしない
  - **B**: 設計役・作業役が作った基準・読み。合否に使わない(参考表示か削除)
- 運営者の発言の原文は、この台帳に逐語で貼らない(要旨を書く)。原文は、その回の作業フォルダの 作成中/_指示_*.md などに写して残す(CLAUDE.md のとおり、依頼者の1通は全文を作業フォルダに写す)。
- 新しい発言が来たら、**置き換える**(古い行は消す。積み上げない)。数・割合・回数・上限は、A の原文があるものだけ合否に使う。それ以外は「参考」と書く。
- 他人(SNS等)の投稿の原文・アカウント名・URLは書かない。
