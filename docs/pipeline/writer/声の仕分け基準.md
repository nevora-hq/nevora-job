# 仕分け基準(声を「悩み」「別枠」「悩み以外」に分ける基準)

規則34(d)の「区分(悩み / 悩みではない)」を決める基準。規則の本文は `.claude/agents/writer.md` の規則34が正で、この文書は区分の線引きだけを書く。声を集める手順は `.claude/agents/voice-researcher.md`。

**対象は、悩み型の記事で声を探すとき(声の探索は、悩み型の記事でも必須にしない。可能な限り行う。声が見つからない・声ゼロでも記事を保留にしない。依頼者の決定 2026-11-20)。** 悩みが入口でない記事(制度・手続きの解説、比較、手順・やり方、用語の整理、最新情報など)は、声の探索が任意なので、この仕分けも要らない。悩み型でない記事に、仕分けのために悩みを作らない。

原文(声)はこの文書に載せない。基準は、元の運営者の確認済みの決定(願いの線引きは案a、別枠-b の新設、曖昧な点の追記)に沿っている。

## 基準の核

**書いた人が、いま困っている事柄を、自分で述べているか。**

声は、下の順に見て、3つのどれかに入れる。区分(悩み/悩みではない)の2値は変えない。「別枠」「悩み以外」は、どちらも区分「悩みではない」。**悩みに数えるのは「悩み」だけ。**

| 仕分け | 条件 | 区分(2値) | 困りが読める |
|---|---|---|---|
| **悩み** | いま困っている事柄を自分で述べていて、**願いの形か、質問が書かれている**(下の「願いに数える形」) | 悩み | ○ |
| **別枠-a** | 困りは読めるが、**願いの形も質問も書かれていない**(困りの一言・状態の説明・決意や感嘆・抜粋が途中で切れた相談文) | 悩みではない | ○ |
| **別枠-b** | 困りが**いま続いていて**、本人の**対処・工夫・経過**が書かれている(助言・共有の形を含む)。願いの形はない | 悩みではない | ○ |
| **悩み以外** | 困っている事柄を述べていない(感想・気づき・助言だけ・解決済み・過ぎた出来事だけ・宣伝・買い物の迷い・特殊な場面・困りを述べない質問) | 悩みではない | × |

## 願いに数える形(案a。運営者の決定)

- **数える:** 「〜したい」「〜てほしい」「教えて(ください)」「どうすれば/どうしたら」「方法・やり方を知りたい」「〜お願いします(助言の依頼)」。
- **質問に数える:** 疑問の形(〜ですか・〜でしょうか・〜のか・〜ありますか・〜いますか)。
- **数えない(→別枠-a):** 決意(〜しないと・〜しなければ)、感嘆・祈り(〜してくれ・〜よ)、状態の訴え(進まない・終わらない・分からない・困る)、愚痴。

## 順番(上から見て、最初に当たったところで止める)

1. **宣伝・広告・転載・啓発の投稿か。** → 悩み以外(除外。件数だけ記録)。副業の題材では、案件・講座・ツールの勧誘や、アフィリエイトの投稿を含む。
2. **書いた人が、いま困っている事柄を述べていないか。** 次のどれかなら、**悩み以外**。
   - 感想・気づき・他の人への助言だけ
   - 解決済みの体験(「申告が終わった」「無事に受け取れた」「解決した」で終わる)
   - 買い物の迷い(サービス・ツールを選ぶだけ)
   - 特殊な場面(ふつうの読者が出会わない場面)
   - **過ぎた出来事の報告だけ**(後悔・出来事の一言で、**今も続く状態が本人の言葉で読めない**)
   - **困りを述べない質問**(制度・用語・仕組みの名前や性質を尋ねるだけで、困る・不安・手が止まっている、などの様子が書かれていない)
3. **「いま続いている」困りが読めて、助言・対処の共有・経過報告の形をしているか。** 読めれば**別枠-b**(悩み以外にしない)。
4. **いま困っている事柄を述べていて、願いに数える形か質問があるか。** あれば**悩み**。
5. **ないか。** → **別枠-a**(困りが読めるので ○)。

## 「いま続いている」の目安

- 続いている: 現在形の不具合・滞り・不安が本人の言葉で書かれている / 習慣や状況が今の時期にもあると読める / 対処の途中で終わっていない(途中経過を含む)。
- 続いていない: 「終わった」「解決した」で終わる / 過去の1回の出来事だけ / 後悔の一言だけ。

## 追記した4点(曖昧だった点)

1. **願いの線引き:** 上の「願いに数える形」のとおり。決意・感嘆は別枠-a。
2. **抜粋切れ:** 本文が途中で切れ(省略記号で終わる)、見えている範囲に願いの形も質問もないときは、**記録の理由欄や記録者の推測で補わず、別枠-a**。質問ページの全文を読めたときは、全文で付け直す。
3. **後悔・出来事の一言・返信:** 「今も続く状態が本人の言葉で読めるか」で分ける。読めれば別枠-a(返信でも、自分の状況が続くと述べていれば別枠-a)。読めなければ悩み以外。
4. **困りを述べない質問:** 悩み以外。

## 判定のくわしい線

1. **質問・依頼が、本人の状況・行為・手続きに向いていれば、困りを述べたものとして数える**(例: 自分の副業収入がこの条件に当てはまるか、これは問題になるか、〔困りごと〕を片づけた人のやり方を教えてほしい)。質問が困りと無関係(制度の名前・用語の意味だけ)なら、困りを述べない質問=悩み以外。ただし、そのとき本文の別の所に、続く困りが本人の言葉で読めれば、別枠-a。
2. **状態の訴え**(〜が進まない・ずっと続く・終わらない・分からない)は、願いに数えない=別枠-a(続いている困りが読める)。**決意の形**(〜しなければ…と思う・〜しないと)も別枠-a。
3. **抜粋が切れていても、見える範囲に願いの形か質問があれば、悩み。** 見える範囲に願いの形も質問もなければ、別枠-a。**見える範囲に、困りの記述もないとき**(質問と宣言しただけ・買い物の話だけ)は、悩み以外。
4. **「今も続く」の読み方:** 現在形の状態(つらい・止まっている・出ている・直らない)、または「結局」「また」「やっぱり」「毎回」など繰り返しを示す語があれば、続いていると読む。過去の1回の出来事・後悔の一言(繰り返しを示す語がない)は、続いていない=悩み以外。
5. **別枠-b は、困りが現在も続くことが本人の言葉で読め、かつ本人の対処・工夫が書かれた声だけ。** 手続きや相談を済ませた体験の報告と、他の人への注意喚起は、悩み以外。
6. **質問は、自分の状況・行為・使っているサービス・やったことが書かれていれば、困りを述べたものとして数える。** それが全く書かれていない一般論・手順の質問だけなら、悩み以外(1と合わせて読む)。
7. **別枠-bは3点がそろうときだけ。** (1)今も続く困りが本人の言葉で読める (2)本人が自分で取った具体的な対処・工夫が書かれている (3)願いの形も質問もない。願いの形か質問があれば悩み(5を、この3点に置き換えて読む)。
8. **過去の1回の出来事で、繰り返しを示す語も現在形の状態もないものは、抜粋切れでも悩み以外。** 抜粋切れで別枠-aにするのは、現在形の状態か繰り返しが見えるときだけ(3と4の補足)。
9. **独り言の疑問・嘆きの疑問(〜なのかなぁ・大丈夫かな)は、願いの形でも質問でもない=別枠-a。** 回答を求める依頼の形(〜ですか・教えて)だけ質問に数える。
10. **質問の形(〜ですか・教えて・どうすれば)で、本人の状況・困りが一言でも書かれていれば悩み。** 題材から少し離れた話(関連する別の悩みなど)でも、本人の状況が書かれていれば悩み。「割れたら別枠-a」は、この線を当てても読みが分かれるときだけに使う(複数の担当が一致して悩みと読んだ声を、割れ扱いで別枠-aにしない)。
11. **「〜した場合どうすれば」は、本人がその状態になったこと・なっていることが読めれば悩み。** 予定・仮定・一般論だけ(「期限を過ぎたらどうなりますか」「〔手続き〕は〔不都合〕が出ますか」)で、本人の経験も状況も書かれていなければ悩み以外(6の再掲)。
12. **買い物・選び方の質問は、本人の状況(〔不都合A〕・〔不都合B〕・〔迷っている事情〕など)が添えてあれば悩み。** 好み・価格・使い切る期間だけなら悩み以外。
13. **他人(家族・知人)の困りを、書いた人が心配して尋ねている声は、困りが具体的に書かれ「どうすれば」の形なら悩み(代理の相談)。** 一般論や注意喚起、特殊な場面は悩み以外。
14. **短い状態の報告(「〔不都合〕が出てきた」)は、つらい・困る・不安などの語がなく、願い・質問・対処もなければ悩み以外。** それらの語があれば別枠-a。抜粋切れで過去の出来事に見えるものは8のとおり悩み以外。

## 別枠の扱い

- 別枠-a・別枠-b は、**悩みに数えない・問いの根拠にしない**。用途は、型・入り口の把握と、企画書の「同じ場面の確認欄」(番号で置く)、導入の場面の言い回しの参考まで(規則34の範囲)。
- 「今何をしたいか」を(推)で埋めて、悩みに繰り上げない。別枠-b は「対処中(書)」と書く。

## 迷ったとき

- 質問に見えるが、質問でなく紹介のとき → 悩み以外。
- 判定が割れたとき → 別枠-a。
- 機微な情報(口座・収入額・借入・勤務先・家族の事情・心身の不調の詳細)は、題材と関係が無ければ原文を保存せず、番号と型だけを記録する(規則34(c)の削除と同じ扱い)。

## 副業の題材での当てはめ(作例。原文ではなく、線の読み方を示すためのもの)

| 声の型(要旨) | 仕分け | 理由 |
|---|---|---|
| 副業の収入を確定申告に書くのか分からない、どうすればいいか教えてほしい | 悩み | 困り+願いの形 |
| 確定申告の期限が迫っているのに手が止まっている | 別枠-a | 続いている困りは読めるが、願いも質問もない |
| 毎月の経費は表計算で記録し、領収書は月末にまとめている。それでも按分の線がずっと決まらない | 別枠-b | 困りが続き、本人の対処が書かれ、願いも質問もない(7) |
| 無事に申告が終わった、簡単だった | 悩み以外 | 解決済み |
| 副業のおすすめの案件サイトを教えて(事情の記述なし) | 悩み以外 | 買い物・選び方の質問で、本人の事情がない(12) |
| 講座の勧誘のリンクつき投稿 | 悩み以外 | 宣伝(順番の1) |
