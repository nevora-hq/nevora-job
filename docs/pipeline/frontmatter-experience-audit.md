# frontmatter体験示唆表現 監査

対象: `サイト運営/記事データ/確定稿/` `サイト運営/記事データ/公開済み/` 配下 全.md(下書きは対象外)
方法: キーワードGrep(体験談を/実際に使ってみた/使ってみたところ/試してみた/効果を感じた/効果を実感した/編集部が実際に/編集部で試した/編集部の体験/してみた結果/してわかったこと/して気づいたこと/使用してみて/使い続けてみて/検証してみた)でヒットしたファイルのfrontmatter範囲を目視確認。

副業の題材で足す検索語: 実際にやってみた/やってみたところ/始めてみた/登録してみた/稼げた/稼いだ/月◯万円達成/収益化できた/受注できた/案件を取ってみた。副業の題材では、体験の示唆が「収入・成果の実績」の示唆を兼ねやすい(例:「実際に月5万円稼げた方法を解説」)。実在しない体験の主張(B5違反)であるうえ、収入・成果を断定・保証する表現として景品表示法の優良誤認(第5条第1号)にも関わるので、description・accordions等の公開テキストに残っていないかを優先して見る。

本文(frontmatter外)側のみでヒットした箇所は、frontmatter対象外なので一覧から除外し、「対象外」に書く。

## 判定の区分

- **矛盾あり**: 体験談を予告しているのに、本文に体験談が無い。
- **矛盾なし・本文側にB5違反の疑い**: 予告と本文は対応しているが、本文に一人称の体験談がある。
- **要確認**: 「試してみたい」「稼げるか試してみたい」等の読者の意向表現。サイト側の実施・体験を主張するものではないので、B5に当たらない可能性が高い。念のため記載する。
- **第三者の体験談**: 一人称ではないので、B5に当たらない可能性が高い。参考情報として記載する。

## 読者像・署名との関係

読者像は年齢・性別を決めず、「副業の〜に興味がある人」「〜で困っている人」のように関心や困りごとで決めるので、読者の意向表現も同じ形で判定する。記事の署名は「NEVORA編集部(運営者: 眞井 虹輝)」で実名の運営者に結び付くため、運営者が実際にはしていない体験を予告・主張する文言は書かない。
