# サイト全体の積み残しタスク

phase単位のドキュメント(`docs/phase2-progress.md`等)に埋もれず追跡できるよう、
サイト運営・サイト本体に関する積み残し事項をここにまとめる。着手時に該当項目を削除する。

## 記事データ

項目を足すときの書き方:

### <件名>(<発見日>発見)
- 対象: `サイト運営/記事データ/<フォルダ>/<ファイル名>.md`
- 症状: 何が起きているか(例: frontmatterに`date`/`updatedDate`が未設定のため、`/sitemap.xml`でこの記事のURLに`lastmod`が出力されない)
- 経緯: どこで見つけ、なぜまだ直していないか
- 対応方法: 何をすれば直るか
- 着手条件: `記事データ/`配下が他セッションの作業と競合しないタイミングであることを確認してから、対象ファイルだけを修正する
